# SkillBridge AI 🚀

An AI-powered career roadmap generator and job screening tool built with Streamlit and Google Gemini AI API.

## Features
- **Career Roadmap Generator:** Generates structured 8-week sprint plans customized to user roles and time commitment.
- **Scam Detector / Job Screening:** Analyzes job listings for red flags (upfront fees, fake offers, urgency) and provides a risk score.

## Tech Stack
- **Frontend & UI:** Streamlit
- **Backend AI:** Google Gemini API
- **Language:** Python
- **Deployment:** Replit
