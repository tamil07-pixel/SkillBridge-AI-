## 📌 About The Project

**SkillBridge AI** is my first full-fledged project created to solve two major challenges faced by freshers and job seekers:
1. Navigating complex career transitions with structured learning plans.
2. Protecting candidates from fake job offers, scam recruiters, and upfront fee frauds.

---

## 🔥 Key Features

* **📌 Career Roadmap Generator:** Generates structured 8-week sprint plans customized to user roles, skill goals, and daily time commitments.
* **🛡️ Scam Detector / Job Screening:** Analyzes job listings for red flags (upfront fee demands, suspicious contact details, fake offer letters, excessive urgency) and provides a safety risk score.
